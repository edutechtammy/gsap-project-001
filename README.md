# GSAP Project 001 - Joe's Coffee Break

A beginner's exploration of GSAP (GreenSock Animation Platform) featuring an animated character named Joe enjoying his coffee.

## About This Project

This is my first GSAP project as I'm learning to create smooth, performant SVG animations. The project features a character with multiple animation sequences including blinking, coffee steam, idle state, lifting, and sipping animations.

## Live Demo

🎬 [View Live Demo](https://edutechtammy.github.io/gsap-project-001/)

## Project Structure

```
gsap-project-001/
├── index.html              # Main HTML file with inline SVG
├── animations/
│   ├── gsap-script.js      # Main animation controller
│   └── joe/
│       ├── joeAloopBlink.js    # Blinking animation loop
│       ├── joeAloopSteam.js    # Coffee steam animation
│       ├── joeIdle.js          # Idle state animation
│       ├── joeLift.js          # Lifting cup animation
│       └── joeSip.js           # Sipping animation
```

## Technologies Used

- **GSAP 3.12.5** - Animation library
- **SVG** - Vector graphics for scalable character design
- **Vanilla JavaScript** - ES6 modules for animation logic

## Features

- Smooth character animations using GSAP timelines
- Modular animation structure with separate files for each action
- Looping animations (blinking, steam effects)
- Interactive character with multiple states

## Running Locally

1. Clone this repository
2. Open `index.html` in a modern web browser
3. No build process required!
